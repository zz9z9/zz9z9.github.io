## 테스트 코드 목적
- 기능 명세
- 버그 예방
- 결함 국소화 (테스트 범위가 작을수록 문제 발생 파악이 빠르게 가능)

## 테스트는 실행하기 쉬워야 한다
- 완전 자동 테스트 : 따로 손댈게 없어야한다.
- 자체 검사 테스트 : 직접 검사하지 않아도 에러를 찾아내 알려줘야 한다.
- 반복 가능 테스트 : 여러 번 돌려도 같은 결과를 얻을 수 있도록
- 독립적인 테스트 : 테스트별로 따로 돌려볼 수 있어야 한다.
