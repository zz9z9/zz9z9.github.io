## 집요하게 문제 해결한 경험 ?
> 소수점 초 반올림

- LocalDateTime와 Timestamp의 정밀도는 나노초, Date는 밀리초이다.
- Timestamp의 nanos가 0보다 크면 MySQL 5.6.4버전 이상부터는 소수점 초가 붙어서 쿼리 파라미터에 세팅된다.
- LocalDateTime의 nano초 부분이 0이면 결과적으로 Timestamp의 nano초 부분도 0이되었다.
- DATETIME과 같은 날짜/시간 자료형에 정의된 소수점 자릿수를 초과하는 부분은 반올림된다.

> DB TLS

- SSL 통신방식
- 특정 서버의 애플리케이션에서 DB 서버와의 SSL 통신에 실패하여 애플리케이션이 실행되지 않는 이슈가 있었습니다.
- SSL 통신을 비활성화하는 방법을 사용할 수도 있었지만, 근본적인 해결책은 아니라고 판단했습니다.
- 결국 JDBC 드라이버를 코드 수준에서 디버깅한 결과,
- DB 서버와의 SSL 핸드셰이크에 기본적으로 TLS1.0과 TLS1.1이 사용되고 있었고,
- 해당 서버의 JDK 버전에서는 이 프로토콜들이 허용되지 않는 사실을 알 수 있었습니다.
- 최종적으로 TLS1.2 버전을 사용하도록 설정함으로써 근본 원인을 해결할 수 있었습니다.

> 롤체인지 후 이슈
1. L4에서 헬스체크 요청 들어옴 -> DB에 질의 요청
2. 질의 실패 (autoReconnect true이면, 다음 질의 때 질의 날리기 전 먼저 ping 검사하라는 변수(needsPing)를 true로 만듦)
- Communications link failure 예외 발생 (health check down)
3. L4에서 헬스체크 요청 들어옴 -> DB에 질의 요청전 먼저 ping 검사 수행
4. ping 실패시 DB 세션에 다시 연결(reconnect)하는 과정 수행
5. (먼저 NativeSession close 후) reconnect 최대 재시도 횟수(default : 3)까지 실패
- Could not create connection to database server. Attempted reconnect 3 times. Giving up. 예외 발생
6. L4에서 헬스체크 요청 들어옴 -> DB 질의를 위해 PreparedStatement 만드는 과정에서 커넥션에 매핑된 NativeSession이 닫혀있는지 먼저 확인
- 5번에서 NativeSession close하고 재연결에도 실패했기 때문에 NativeSession은 닫혀있는 상태이므로, No operations allowed after connection closed. 예외 발생
- 즉, NativeSession만 체크하고 예외 던지므로 DB가 롤체인지 되어 살아난 것과는 관계없이 질의를 할 수 없게됨

※ 롤체인지 2초때는 3또는 4에서 성공한 것으로 보임

- PoolCleaner(org.apache.tomcat.jdbc.pool.ConnectionPool.PoolCleaner)가 5초(timeBetweenEvictionRunsMillis 기본값)에 한번씩 idle 큐에 있는 커넥션들의 DB 세션 유효성 검사

## 최근 업계 동향 ?
- 양자컴퓨터
  - 큐비트(Qubit, Quantum Bit): 0과 1을 동시에 표현할 수 있는 "중첩(superposition)" 상태를 가짐.
  - 병렬 연산: 여러 상태를 동시에 계산할 수 있어 특정 유형의 문제를 훨씬 빠르게 해결 가능.
  - 중첩(Superposition)과 얽힘(Entanglement) 덕분에 병렬 연산이 가능하여 특정 문제를 기존 컴퓨터보다 압도적으로 빠르게 해결할 수 있음.
    - 중첩 : 입자의 상태를 확률적으로 표현, 예를 들어, 어떤 큐비트가 |0⟩ 상태와 |1⟩ 상태가 각각 50% 확률로 존재한다고 하면, 이 큐비트는 실제로 |0⟩이거나 |1⟩가 아니라 두 상태가 섞여 있는 것
    - 우리가 관측하는 순간 0 또는 1 중 하나의 값으로 "확정"됩니다. 이게 바로 양자의 확률적 특성입니다.
    - 고전 컴퓨터에서는 N개의 비트가 있으면 한 번에 하나의 값만 저장할 수 있습니다. 그러나, 양자컴퓨터에서는 N개의 큐비트가 있으면 2^N 개의 상태를 동시에 표현할 수 있습니다.
  - 예시: 암호 해독, 분자 시뮬레이션, 최적화 문제 등.

  - 이 모델은 이전 버전인 GPT-4에 비해 사용자 프롬프트를 이해하는 능력이 향상되었으며, '환각(hallucination)' 현상이 크게 감소했습니다.
  - 현재 GPT-4.5는 ChatGPT Pro 구독자와 일부 소프트웨어 개발자에게 우선 제공되고 있습니다.

- 클로드(Claude)의 최신 버전: 클로드 3
  - Anthropic은 2025년 1월, 클로드 3(Claude 3)를 출시했습니다.
  - 이 모델은 이전 버전에 비해 자연어 처리 능력이 향상되었으며, 더 긴 문맥을 처리할 수 있는 능력을 갖추고 있습니다.
  - 또한, 클로드 3는 사용자 프롬프트에 대한 이해도가 높아져 보다 정확하고 관련성 있는 응답을 제공합니다.
