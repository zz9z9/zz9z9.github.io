- 서비스 레이어에서 Exception을 일일이 잡으면, 저수준 구현에 밀접하게 의존하고 있는것. 따라서 ClientExceptionMapping 이러한 별도의 예외 처리하는 클래스를 두는게 좋다고 생각.
  - HttpStatus도 신경쓸 필요가 없어짐

```java
public class ClientExceptionMapping {
    public static RuntimeException translateException(Exception ex) {
        if (ex instanceof LockAlreadyAcquiredException) {
            return new ClientModificationNotAllowedException(
                String.format("이미 %s 처리 중인 고객입니다.", ((LockAlreadyAcquiredException) ex).getLockType().getName()),
                HttpStatus.CONFLICT
            );
        } else if (ex instanceof DuplicateKeyException || ex instanceof ConcurrentModificationException) {
            return new ClientModificationNotAllowedException(ex.getMessage(), HttpStatus.CONFLICT);
        } else {
            return new ClientModificationNotAllowedException("알 수 없는 오류가 발생했습니다.", HttpStatus.INTERNAL_SERVER_ERROR);
        }
    }
}
```
